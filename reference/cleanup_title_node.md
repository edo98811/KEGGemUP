# Cleanup the title node from a KEGG igraph object

Cleanup the title node from a KEGG igraph object

## Usage

``` r
cleanup_title_node(g)
```

## Arguments

- g:

  The igraph object

## Value

An igraph object, without the node originally kept as "TITLE:..."

## Details

Strips away the node starting with the `TITLE:` label. In some
situations, that node might not be too heavily needed...
